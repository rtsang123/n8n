# /prep-listing

Property or seller, if given: `$ARGUMENTS`

## Non-negotiable first step

Read `context/voice-profile.md` (stop and point to `/brain-dump` if
missing), then `context/market.md`, `context/positioning.md`, and
`context/listing-process.md`.

## 1 — Get the specifics

If `$ARGUMENTS` is empty, ask for the address (or neighbourhood, if not
confirmed), what the seller has said so far, and any comps already
gathered. Check `listings/prepped/` for an existing sheet on this address —
if found, this is an update, not a fresh build.

## 2 — Build the sheet

Assemble, in the owner's voice:

- **Seller snapshot** — situation and motivation (timeline, why they're
  selling, what they care about) — only what was actually said, `?` for
  unknowns.
- **Pricing narrative** — a range and the story behind it, built ONLY from
  comps the owner supplied or already in context; if none were given, say
  so and ask rather than inventing numbers.
- **Competitive angle** — from `context/positioning.md`: who else this
  seller is likely interviewing and how the owner differs — talking points,
  not trash talk.
- **Likely objections** — 2–3, drawn from `context/listing-process.md`
  (their own pricing philosophy) and common seller pushback (price,
  commission, timing) — each with a response in their voice.
- **Table questions** — 3–4 questions worth asking the seller, aimed at
  surfacing motivation and expectations early.

## 3 — Save and hand off

Save to `listings/prepped/<address-slug>.md`, dated. Show the sheet, ask if
anything needs adjusting. This is meant to be skimmed once in the car, not
memorized.
